# Day Oneness

予定・日記・ToDoを一日単位でまとめる、個人用のWebアプリ（PWA）です。

- データはすべて使っている端末のブラウザの中に保存され、このリポジトリには含まれません。
- バックアップは、アプリの「設定 → 書き出し」から取れます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| index.html | アプリ本体 |
| manifest.webmanifest | ホーム画面に追加したときの名前・アイコン・色 |
| sw.js | オフラインでも開けるようにする仕組み（Service Worker） |
| icon-192.png / icon-512.png / apple-touch-icon.png | ホーム画面用アイコン |

## 更新するとき

`index.html` を新しいものに差し替えるだけで、次にアプリを開いたときに反映されます。
